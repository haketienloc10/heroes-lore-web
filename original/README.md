# Bản game gốc

Đặt **Heroes Lore: Wind of Soltia v2.1.2** vào `original/heroes-lore-v2.1.2.jar` (không commit JAR).

Tạo fingerprint bằng `npm run hash:original`. Chỉ commit `SHA256.txt` sau khi xác nhận đó đúng là bản chuẩn cần phân tích. Không giả định file tải từ cùng một trang luôn có SHA-256 giống nhau.
