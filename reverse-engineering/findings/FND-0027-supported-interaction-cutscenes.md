# FND-0027 — Capability-checked event cutscene trigger dispatch

## Scope

Run type-1/current-cell, type-2/ahead, type-0/current-cell, and type-3/ahead event scripts through the ordered interpreter when the complete command stream is implemented and rendered. Keep unsupported streams on the existing conservative dialogue/flag/transfer path.
