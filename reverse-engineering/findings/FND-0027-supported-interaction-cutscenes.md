# FND-0027 — Capability-checked event cutscene trigger dispatch

## Scope

Run type-1/current-cell, type-2/ahead, type-0/current-cell, and type-3/ahead event scripts through the ordered interpreter when the complete command stream is implemented and rendered. Keep unsupported streams on the existing conservative dialogue/flag/transfer path.

## Browser implementation

- `canRunEventCutscene` fast-forwards a fresh interpreter state to validate every command and its structure before `WorldScene.dispatchInteractionTrigger` or `tryMapTransition` selects the ordered runner. Type 1/2 interactions and type 0/3 map triggers use the same complete-stream gate. Inventory-gated rows now match the source category/item/count predicate; unsupported command forms or invalid direction/transfer sequences do not pass the stream gate. M54 corrects NPC cutscene-state synchronization to use the active map placements; M55 adds source-shaped item quantity handling; M56 renders opcode-24 flashes; M57 applies opcode-46 hiding; M58 renders emotion opcodes 49/50; M59 adds camera pan opcodes 34/35/37/38; M61 models the supported experience and skill awards; M62 threads inventory through trigger selection; and M63 adds opcode-25 shake and paired opcode-42/43 tile writes. M65 adds opcode-2 choices; M66 initially models opcode-31 forward jumps; M67 corrects opcode 10/13/14/12 player changes and keeps game/quest flags separate; M70 adds opcode-19 combo limits; M76 adds opcode-36 fixed-camera state and opcode-39 direct tile positioning; M77 adds service handoffs for opcodes 44/45/48; M174 adds quest-flag-29 toggle semantics; M269 adds opcode 27 and signed relative opcode-31/32 jumps, yielding one source tick on backward/self jumps. Focused tests cover both map-59 choice branches, forward-jump bounds, new M269 no-op/jump cases, player-state/flag command order, NPC images, camera commands 36/39, and commerce transactions. M269 has no browser/J2ME comparison. Map-transition trigger polling is gated on an actor movement boundary; M64 demonstrates the map-53→54 transfer and confirms map 54's ahead type-3 return does not fire while idle.
- Supported interaction scripts reuse the modal dialogue/cutscene presentation, apply game and quest flags as commands execute, render source dialogue without the New Game Ronin speaker substitution, and perform source-ordered waits and transfers. The older conservative interaction interpreter remains available for its limited stream subset.
- M99 implements standalone opcode 8 as an ordered map-local hero-position effect; opcode 7 continues to consume the next opcode 8 as a map-transfer destination. Capability checks interpret standalone coordinates as signed bytes and reject positions outside the active map. `WorldScene` applies newly emitted position changes once to the actor before syncing the cutscene state.

- The source opcode-name table calls 46 `HIDE_NPC` and 47 `SHOW_NPC`. In `ag`, opcode 46 clears `ab.d` and calls `n.f()` to remove its occupied cells; opcode 47 sets `ab.d` and calls `ab.a(c,d)` at the actor's current pixel position. `javap -c -p ag` confirms both dispatch branches, and `javap -c -p ab n` confirms the reposition call clears the NPC's occupied cells and re-registers them when it is standing. M160 adds opcode 47 to the rendered-command capability gate and emits a visible state. M161 retains hidden startup actors so later commands can reveal their sprites, and rebuilds NPC occupancy from live pixel positions only for visible, standing actors. The 72 extracted event-operation files contain 387 scripts, none of which uses opcode 47, so this remains source-command support rather than evidence of a reachable campaign use.
