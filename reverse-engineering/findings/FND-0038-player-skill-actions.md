# FND-0038 — Player skill action timing, ranks, and effects

## Question

Which source skill-action states and effects can be implemented for the browser, and what does the current replay establish?

## Reference and method

- Reference JAR: `original/heroes-lore-v2.1.2.jar`, SHA-256 `7eb032297967f5d8382cc4f1ab5c3016459e01b235b42a3b88c6a8bfe46c5f61`.
- Inspected JADX source for `o`, `an`, `ak`, `ce`, and `t` in `reverse-engineering/decompiled/sources/defpackage/`.
- Cross-checked `o.e()`, `o.a(int)`, `o.m112a()` (named `a()` in bytecode), the skill-effect branches, action selector, and skill tables using `javap -classpath original/heroes-lore-v2.1.2.jar -c -p o` and `javap -classpath original/heroes-lore-v2.1.2.jar -c -p ak`. The bytecode confirms the skill-to-element pairing, per-level rank thresholds, skill-4 level-1 guard flag, and its four raw random draws. `an.f(int)` and the save/restore methods were checked against JADX source. No J2ME runtime comparison was performed.
- Controlled browser replay: Chromium 156.0.8078.4, REA Evidence `ev_6b16e542dbf87cb912d070873a9fdcef4f14b5be7cbb53eabd1ed7fc5185449d`. The ignored local capture manifest and screenshot are under `reference/screenshots/web-render/M100-player-skill-action/`.

## Verified source behavior

- `o` stores six skill IDs with base ranks `[1,1,1,1,10,20]`. Its per-level unlock ranks are `[1,9,20]` (the table also contains 30 for another rank gate); each skill has three charge counters. Skill ID 0 starts at charge `[56,280,280]` update ticks. Its action duration for levels 0 and 1 is zero, while level 2 has duration 10. The effect end ages for those levels are 16, 9, and 161 (`o.java:8–12, 107–132`; class initializer and `o.e()`).
- `an.f(int)` multiplies the awarded source experience by four, updates hero experience, then passes that same multiplied amount to the currently active skill object `f72a`. `o.a(int)` accumulates skill experience in `f282a`; its threshold is `rank³ − rank² + 80 × rank`. It subtracts thresholds and increments `f281a` until the remainder is below the current threshold. At rank 9, it selects the second skill level pointer (`o.java:62–76`; `an.java:821–842`). Thus only the active skill gains rank experience, and event and enemy experience use the same rule.
- J2ME save data writes each learned skill's ID, short rank, skill experience, and two selected level pointers in fixed `f71a` slot order, then stores the active skill as a separate slot byte (`an.java:1131–1155`). Restore constructs each skill in that order, restores rank and experience, then selects the separately stored active slot (`an.java:1223–1241`). The charge counters are initialized by the constructor rather than included in these saved fields. M329 updates the web save model to preserve that distinction: `skillIds` retain learned-slot order, `activeSkillId` stores the selected skill, and the source RMS adapter translates it to/from `activeSkillSlot`. Older version-one browser saves without the field default to their first listed skill, matching the previous web representation.
- The skill list screen `bl` locates the active skill's current slot when it opens; selecting a row changes the `f72a` pointer without moving the learned skill in `f71a` (`bl.java:8–20, 34–43`; `an.java:1016–1023`). That screen also opens the level-assignment screen `bm`, which selects one of two action buttons, assigns an unlocked level slot, and rejects assigning the same level to both buttons (`bl.java:26–51`; `bm.java:15–31`). The web skill list now keeps the same stable row order, highlights the explicit active skill, and reopens on its active row. A newly constructed skill starts button 1 on level 0; button 3 is assigned level 1 only when the base rank unlocks it. Reaching rank 9 assigns level 1 to button 3 and resets that level's charge (`o.java:49–58, 107–132`; `o.java:71–76`).
- Starting an action stores the actor tile plus its facing vector, switches to state 1, and initializes the action timers. State 1 becomes state 2 after ten updates only when duration is positive; otherwise it becomes state 3. State 2 decrements its duration and enters state 3 when the counter expires. State 3 runs the effect each update and returns to idle after its finish flag and frame 11 (`o.java:135–212`; bytecode of `o.e()`).
- Skill ID 0 maps to element code 1 (`o.m112a()`). Level 0 uses power `(rank × 3) + 40 + Will` and calls `ak.a(int, byte)` on source grid cells. Its updates hit: the facing cell at ages 1 and 5; one, two, and three cells forward at ages 2/6, 3/7, and 5/9 respectively (age 5 therefore hits both the facing cell and the three-cell cell); and the two diagonal cells three cells forward at ages 8 and 12 (`o.g()`, `o.java:386–419`). `ak.a(int, byte)` applies the target elemental multiplier and skips ordinary defense and evasion (`ak.java:433–454`).
- Skill ID 0 level 1 creates its short action animation, applies status 5, and sets `an.f52d`. The `ce` duration table gives status 5 a 140-update lifetime, and `an.m15a()` multiplies base attack power by 3/2 while the flag is set (`o.java:224–229`; `ce.java:8–15`; `an.java:590–618`).
- Skill ID 0 level 2 unlocks at rank 20, has charge 280, a ten-update state-2 duration, and effect end age 161. At effect age 0 it starts a 160-update status effect and sets `an.g`. Before ordinary damage/evasion processing, `an.a(ak,short,byte)` directly subtracts `(skill rank × 2) + 40 + Will` HP from the attacking enemy through `ak.b(int)`; this counter-hit ignores defense, element multipliers, and evasion (`o.java:8–12, 231–239`; `an.java:753–763`; `ak.java:528–535`).
- Skill ID 1's rank-1 slots each have a four-update state-2 duration. At effect age 0, level 0 calls `an.c(30)` to add 30% of maximum HP and level 1 calls `an.e(20)` to add 20% of maximum SP. `an.b(int)` and `an.d(int)` clamp the result to zero and the corresponding maximum, then refresh the matching HUD resource (`o.java:242–254`; `an.java:796–829`). The ten-update windup and four-update active phase let this skill reach the source state-2 action-target window.
- Skill ID 1 level 2 unlocks at rank 20, has charge 270, a ten-update state-2 duration, and effect end age 81. At age 0 it sets `an.f54h`; while that flag is set, each passive HP or SP recovery pulse doubles its normal amount without changing the corresponding timer interval. The flag clears at age 81 (`o.java:8–12, 250–268`; `an.java:252–266`).
- Skill ID 2 level 0 maps to element code 3. Its power is `(rank × 3) + 35 + floor(Will × 3 / 2)`; it hits the action cell one tile ahead at effect ages 2/6, then two, three, and four tiles ahead at ages 3/7, 4/8, and 5/9. `o.h()` consumes two `g.a(-4,4)` draws for camera offsets on ages 0–5, and `o.j()` schedules effect code 4 over ages 0–7 (`o.java:87–96, 386–442, 655–675`).
- Skill ID 2 level 1 has a four-update state-2 duration. At effect age 0 it adds status 6 and sets `an.f53e`; `ce(6)` lasts 160 updates, after which `an` clears the flag. Incoming damage subtracts twice `an.f65i` while the flag is active. That derived defense combines equipment slots 1–4 with the source base attributes (`o.java:270–281`; `ce.java:8–15`; `an.java:282–292, 779, 1074–1085`). Its active action also reaches state 2.
- Skill ID 2 level 2 unlocks at rank 20, has charge 220, no state-2 duration, and effect end age 13. At effect age 0 it removes all active status entries and clears the attack-up and defense-up flags (`f52d`, `f53e`) (`o.java:8–12, 283–290`).
- Skill ID 3 level 0 maps to element code 1. Its four-update state-2 action has charge 80 and an effect end age of 25. Damage power is `(rank × 3) + 35 + Will`; three source helpers start at ages 4, 10, and 16 and add one cardinal cross cell at each distance every three updates. Separate `a(byte,int,int)` calls schedule effect type 5 at the action cell and cardinal rings up to distance 3, starting at ages 0, 6, and 12. That overload creates visual effects; the element-matched instant-kill helper is a separate overload and is not called by skill 3 level 0 (`o.java:87–96, 293–304, 464–490, 685–714`).
- Skill ID 3 level 1 requires skill rank 9, has a 270-update charge, ten-update state-2 duration, and effect end age 81. Each effect update draws four raw `nextInt()` values to build two offsets inside a radius-two Manhattan diamond. Through age 79, it applies element-1 damage at both action-tile offsets with power `rank + 45 + floor(Will × 3 / 2)`; the same offsets schedule visual effect type 6. Ages 80 and 81 still consume the four random values but no longer damage or schedule sprites (`o.java:305–310, 445–462, 677–683, 734–739`).
- Skill ID 3 level 2 unlocks at rank 20, has a 270-update charge, an eight-update state-2 duration, and effect end age 8. At effect age 0, its instant-kill helper checks the action cell and the next three cells forward, then calls `ak.c(byte)` only for matching element-1 enemies that are not `au` subclasses. Its companion feedback helper adds `bi` feedback to matching enemies or schedules type-10 scenery in the next three cells (`o.java:311–317, 492–502, 716–728`; `ak.java:545–552`).
- Skill ID 4 level 0 is the attack granted by map-12 script 1's opcode 18. Its source base rank is 10, its charge is 80, its action has zero state-2 duration, and the effect ends at age 31. It maps to element code 2 and uses power `(rank × 3) + 35 + Will`; helpers starting at ages 4, 10, and 16 expand cardinal crosses at five-update intervals. Separate type-7 visual calls start at ages 0, 6, and 12 (`o.java:8–12, 87–96, 320–330, 685–714`; map-12 script 1 `[18,0,0]`).
- Skill ID 5 level 0 has base rank 20, an 80-update charge, no state-2 duration, and effect end age 31. It maps to element code 3 and uses power `(rank × 3) + 35 + Will`; helpers starting at ages 4, 10, and 16 expand cardinal crosses at five-update intervals. Its separate type-4 visual calls start at ages 0, 6, and 12 (`o.java:8–12, 87–96, 353–366, 464–490`; `m112a()` maps IDs 2 and 5 to element code 3).
- Skill ID 5 level 1 requires rank 9, has a 270-update charge, ten-update state-2 duration, and effect end age 87. Each effect update consumes four raw `nextInt()` draws for two radius-two offsets. Through age 79 it applies element-3 damage at those two cells with power `rank + 45 + floor(Will × 3 / 2)`; ages 80–87 still consume the draws but do no damage. The same offsets schedule type-6 visuals, now rendered from the extracted skill-effect stream through the shared tile-effect renderer (`o.java:353–366, 445–462, 677–683, 734–739`).
- Skill ID 5 level 2 uses the same rank-20 unlock, charge, eight-update action, and age-0 forward sweep as skill ID 3 level 2, but matches element code 3 and creates skill-5 `bi` feedback on matching enemies (`o.java:371–377, 492–502, 716–728`).
- `n.b(Graphics, x, y)` advances each actor's attached `e` effects after drawing its body; both `an` and `ak` use this vector. `bi` consumes its delay one paint at a time, draws the requested `/grd/spr` stream at the actor anchor, increments one frame per paint, and ends at its constructor duration. For skill 0 level 2 it cycles atlas images 0/1 at y offsets 9/12. The skill-3/5 sweep's `o.a(short)` adds a target-attached `bi` to matching non-`au` enemies and otherwise creates type-10 scenery (`n.java:336–344`; `an.java:683–716`; `ak.java:68–108`; `bi.java:17–73`; `o.java:716–728`).
- Skill ID 4 level 1 is unlocked at its base rank 10. It has charge 270, a six-update state-2 duration, and effect end age 81. Every effect update consumes four raw `nextInt()` draws and schedules up to two type-8 visuals from radius-two offsets. While the player is within Manhattan distance 2 of the action tile it sets `an.f`; `an.a(ak,short,byte)` returns before enemy damage or status processing while that flag is set. At age 81 the skill clears the flag. The visuals are separate from the guard effect (`o.java:332–342, 734–739`; `an.java:753–764`).
- Skill ID 4 level 2 unlocks at rank 20, has charge 220, a six-update state-2 duration, and effect end age 16. At effect age 0 it creates a `bi` stream for skill 4 level slot 2 with duration 15, then restores 20% of maximum HP and SP (`o.java:8–12, 320–351`; `bi.java:17–28`; `an.c(int)` and `an.e(int)`).
- `ak.i()` retains a state-2 action reference. For an existing actor reference it continues pursuit without retargeting when `o.m113a()` is false; otherwise it selects an in-range state-2 action on `g.a(0,9) < 7`, falls back to the actor, then returns no target (`ak.java:198–242, 553–571`). The selector's action target cannot be reached by either currently ported skill-0 level because both have zero duration.

## Limits

M266 is the first live browser capture here to inspect skill action state and enemy HP: it confirms that Fireball input damages a map-61 enemy, but it does not isolate pulse count or compare damage/timing with J2ME. M462 adds a natural browser state-2 action-target observation for skill 1. The M100 capture still does not prove a landed damage pulse. M101–M112 and M119–M125 have no successful skill-action browser capture. M119–M125's rank growth, button selection, and skill effects have focused unit coverage only. A controlled M119 browser attempt returned REA `execution_failure` before usable evidence; provider cleanup could not be confirmed (the error listed no resources), and local `rea doctor` is unavailable. J2ME rank/save parity, RNG sequence, exact timing/damage/visual parity, and skill actions 0–5 outside this one browser encounter remain open. Tile and attached `bi` streams render on 71 ms web updates; source `bi` advances on paint calls, so the update-to-paint cadence has not been compared.
