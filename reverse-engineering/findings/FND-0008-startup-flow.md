## Source flow

1. `be` is the main menu. It paints the purple background, tiled paper panel and selection animation; the English labels resolve to New Game, Load Game, Options, Help, About and Exit. `bg` stores the localized text IDs and draws them with the small bitmap font.
2. Selecting New Game opens `bx` for the available first hero, Ronin (hero ID 6). Confirming opens `bj`, which lets the player toggle two of three Guardians. The confirmation screen begins on No; selecting Yes calls `m.a(false, heroId, guardianSelections)`.
3. Fresh-game initialization clears the game/quest bit arrays and sets game flag 0. The hero start tuple in `m` for hero ID 6 is map 0, tile `(22,4)`. `bt` loads the selected hero's map and its data before returning to the world canvas.
4. The opening screenshot shows the town scene and `[Ron] Are you sure you want to quit your job?`. Map `00`'s auxiliary string table indexes locale string IDs. Script 9 begins with cutscene commands, includes dialogue references `[1,4,0]` through `[1,27,0]` (24 locale-backed entries), and ends with map-change commands `[7,64,1]`, `[8,9,8]`. The first locale entry is `'$[Reah] Are you sure you want to quit your job?'`; the browser applies the speaker substitution visible in the reference screenshot for this selected route. The observed W input is a skip input, and the resulting source screen is map 64 at the bed.

## Asset extraction and browser implementation

- `fonts/small.mf` contains an indexed PNG atlas, ASCII glyph X offsets and font metrics. `decode_bitmap_font()` extracts `fonts/small.png` and `fonts/small.json` into the ignored generated-asset directory; the browser uses those glyphs for its title screens.
- `lang/language.en-GB` uses an offset-indexed table of Java modified UTF-8 records. `decode_language_resource()` extracts 2,378 indexed strings to ignored `language/en-GB.json`; the opening dialogue now reads locale entry 1621 instead of duplicating its sentence in scene code.
- `StartupFlowScene` recreates the source menu panel from `/sgui/mm/etc`, renders the Ronin portrait from `/sgui/mm/face`, and draws the three Guardian sprites from their source atlases. Help reads the four handset topics in `/sgui/help.tdf` and paginates their en-GB text using the source 130-pixel width and 11-line page size. About uses the localized copyright, website and support text plus the pinned MIDlet name, vendor and version. Exit shows the source confirmation and maps Enter/Escape to Yes/No; Yes attempts to close the tab and displays a browser-specific close-tab screen if the browser keeps it open.
- M303 renders source `bf` startup states 10 and 1 before the menu. State 10 settles the original `/img/logo/004` Hands-On mark, applies the source phase/offset sequence, then completes after 58 modeled 20 ms updates; state 1 draws `/img/title1/002`, `/003`, and `/004` at the source component positions `(60,117)`, `(112,117)`, and `(153,94)`. Keyboard or pointer input advances from brand splash to title and then menu. Game-over and ending title returns use the source menu path and skip these cold-start screens. The transition model has unit coverage; M463 adds a post-change Chromium capture, M464 and M469 compare Ronin and Guardian frames to their prior source images, M472 captures the opening dialogue, and M478 captures the natural route through the bedroom. No J2ME timing comparison exists for the new startup splash.
- After confirmation, the browser starts map 0 at tile `(22,4)` with fresh-game flag 0. Map 00's descriptors select action block 2; its opcode-105 actions hide static NPC placements 2, 0 and 4. Static placement 1 (NPC image 16 at `(19,4)`) remains visible in both the source operation table and the saved opening frame, so the browser renders it through the map's normal NPC placement path.
- The opening overlay resolves all 24 opcode-1 references in map-00 script 9 through the extracted auxiliary string IDs and locale table. Enter or Next advances the text pages; M21 captures the first three. W or clicking Skip resolves map-00 trigger 10, type 0, with game flag 0, then applies the script's game-flag sets 54 and 87 before the map-64 destination. World Enter dispatches type-1 current-cell and type-2 ahead-cell triggers with the source flag predicate. The supported subset now resolves dialogue, game/quest flag changes, BGM markers, end, and a paired map-transfer/hero-position command; dialogue can be advanced before a decoded transfer is applied. An unseen destination is fetched only when its map, collision, decoration and event resources all exist; M23 captures one type-3 transfer from map 0 to map 79. The JAR lacks `.evt` files for nine base maps, and five decoded transfer commands target four of those maps; runtime reachability/handling remains unresolved. Loaded maps are keyed by map ID and region-specific variants remain unverified. Unit tests cover the supported subset; other trigger families have not been captured in the browser. Other gameplay commands remain rejected during normal interaction; cutscene movement, delay, actor direction, camera and screen commands are still not interpreted. This is not a general event interpreter.

## Limits and next work

On a cold start the browser now models the source brand and title screens before the main menu; game-over and ending returns skip that startup sequence. No post-change browser/J2ME capture verifies their rendered pixels or timing. Load Game reads the web app's limited localStorage save; Help and About display source-backed pages, and Exit uses browser tab semantics. Only Ronin is available in New Game. The opening text pages progress, but the cutscene movement/camera sequence is fast-forwarded or skipped as a group. The house-to-outside route and one map-79 transfer are replayable; region-specific variants and other trigger families remain unverified. Dynamic HUD values, general event commands/dialogue, full save-state persistence, NPC AI/animation, combat and the campaign remain open.
