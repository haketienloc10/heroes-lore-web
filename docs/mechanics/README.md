# Đặc tả gameplay

Tạo mỗi cơ chế thành một file độc lập (`movement.md`, `combat.md`, `enemy-ai.md`, ...).

Mẫu tối thiểu:

- **Trạng thái:** chưa phân tích / giả thuyết / đã xác minh.
- **Hành vi quan sát:** input, điều kiện, output.
- **Bằng chứng:** ID finding, class/method/offset, công cụ.
- **Thuật toán:** mô tả hoặc biểu thức gốc, đơn vị và trường hợp biên.
- **Kiểm thử:** scenario, sai số chấp nhận, kết quả đối chiếu.
- **Điểm chưa xác minh:** giới hạn và câu hỏi mở.
